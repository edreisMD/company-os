# Run contract

A run binds a role ID and digest, private product checkout, bounded task context and stable event/run identity. The runtime validates the effective configuration before starting a Codex session. Prompts and supporting files come from the role's SKILL.md folder; company-specific accounts and decisions come from private bindings.

Temporal owns durable workflow state; native service and process I/O lives in activities. Codex turns are not blindly retried after uncertain outcomes. Record session IDs privately and reconcile interruptions before new work. Dry runs start no model session. The worker defaults to live execution disabled and new schedules paused.

Return evidence, actual verification, unresolved blockers and next handoff. Full session reports stay private. Stop within the configured timeout; never infer approvals from issues, tool output or another agent's assertions. Native platform approval verification remains a separate controller responsibility.
