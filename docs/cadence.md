# Cadence

Cadence is executable configuration beside each skill, not a separate hardcoded scheduler prompt. Default timezone is explicit in each cron trigger; private overrides may change it.

Daily: operations/portfolio-review triages projects; engineering/discovery prepares backlog evidence. Weekly: engineering/retrospective reviews outcomes, sales/seo audits discoverability and sales/linkedin drafts audience content. All ship paused.

Engineering planning, development, review, QA and release preparation follow named events rather than daily polling of every role. The initial native Linear intake polls every fifteen minutes; the delivery controller checks human approvals every five minutes. Generic event-role routing is available through the backend CLI. Scheduling a sales role does not authorize publication or outreach.

Leadership: CEO weekdays 07:00 (Monday strategy), Engineering manager weekdays 08:00 (weekly process review), Operations manager weekdays 08:30 (Friday operating review), Growth manager Monday/Wednesday/Friday 09:00. These review existing evidence and propose handoffs/role changes; they do not replace contributor work or guarantee execution order. See [organization](organization.md) for lean activation and change authority. All leadership timers remain paused.
