# CompanyOS

Choose the role matching the requested outcome and read its SKILL.md. Each role is independently invocable; its adjacent temporal.yaml defines runtime triggers, not additional action permissions.

- Product opportunity or backlog evidence: engineering/discovery/SKILL.md
- Implementation plan: engineering/planner/SKILL.md
- Approved implementation: engineering/developer/SKILL.md
- Code review: engineering/reviewer/SKILL.md
- Acceptance testing: engineering/qa/SKILL.md
- Release readiness: engineering/release/SKILL.md
- Weekly engineering review: engineering/retrospective/SKILL.md
- New project configuration: operations/project-setup/SKILL.md
- Portfolio priorities: operations/portfolio-review/SKILL.md
- LinkedIn drafts: sales/linkedin/SKILL.md
- Search discovery: sales/seo/SKILL.md

Read only the selected role and its needed references. Honor the user's authorization and the private project's boundaries. Do not infer permission to publish, deploy, send messages or spend from a role name or trigger. Private accounts, credentials, decisions and run reports stay outside this public catalog.
